## What Was Added and Why

### Business Motivation
The original dashboard surfaced **what** was selling (products, categories, regions)
but not **how** sales were happening. Two critical dimensions were unused in the
`data/sales.csv` source: `channel` and `sales_rep`. Stakeholders needed visibility
into which sales channels (Online, In-Store, Wholesale) drove the most revenue and
which sales reps were top performers — both filterable by quarter.

### New Functions

#### `build_channel_bar(df: pd.DataFrame) -> go.Figure`
- Renders a vertical bar chart of total revenue grouped by sales channel
- Uses `plotly.graph_objects.Bar` with channel-specific colors:
  - Online → `#2196F3` (blue)
  - In-Store → `#4CAF50` (green)
  - Wholesale → `#FF9800` (orange)
- Sorted descending by revenue so the highest channel appears first
- Hover template: `<b>Channel</b><br>Revenue: $x,xxx`

#### `build_rep_leaderboard(df: pd.DataFrame, n: int = 5) -> go.Figure`
- Renders a horizontal bar chart of the top N sales reps by total revenue
- Uses `plotly.express.bar` with a green sequential color scale
- Default `n=5`, configurable via parameter
- Sorted ascending so the highest rep appears at the top of the chart
- Hover template: `<b>Rep Name</b><br>Revenue: $x,xxx`

### Dashboard Integration
Both new charts are:
- Added to a new **"Channel & Rep Performance"** section below the existing grid
- Fully integrated with the existing **quarter-filter dropdown**
- Rendered via `Plotly.react()` in JavaScript alongside all existing charts
- Pre-computed for all quarters (Full Year, Q1, Q2, Q3, Q4) at build time

## How to Run and Verify

### Generate the Dashboard
```bash
pip install -r requirements.txt
python dashboard.py
# Output: dashboard.html
open dashboard.html  # macOS
```

### Run the Test Suite
```bash
pytest tests/ -v
# Expected: 31 passed
```

### Verify New Charts Manually
1. Open `dashboard.html` in a browser
2. Scroll to the **Channel & Rep Performance** section
3. Confirm three bars appear in the Channel chart (Online, In-Store, Wholesale)
4. Confirm five reps appear in the Rep Leaderboard
5. Use the quarter dropdown — both charts should update with each selection
